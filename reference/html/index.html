03 / Approach

How I work

My design philosophy centres on systems thinking, cross-functional collaboration, and bridging the gap between design tools and production code.

Systems over screens

I don't design pages — I design the building blocks that compose into pages. Tokens, primitives, components, and patterns that scale across any surface.

Vibe coding

I work directly in the codebase alongside engineers — writing, adjusting, and refining components in real-time. Design intent doesn't get lost in translation.

Design ↔ engineering

The best design systems are co-owned. I build trust with engineering through shared governance — Storybook, Widgetbook, code reviews, and joint ownership.
